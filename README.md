# FieldTrace

This is for my Year 3 Semester 1 Computer Science Final year project 

A Low-Cost IoT and Web Application Platform for Monitoring Regional Soil and Climate Variables

FieldTrace is an IoT-based environmental monitoring platform designed to collect, transmit and visualize soil and climate data using low-cost embedded devices and a web application.

Problem statement
Agricultural decisions often depend on environmental conditions such as soil moisture, temperature and climate variables. However, access to affordable monitoring systems remains limited.

Objectives
1. Design a low-cost IoT sensor node.
2. Develop a web platform for viewing collected data.
3. Store and manage environmental measurements.
4. Apply analytics to identify patterns in collected data.

System archecture
ESP32 Sensor Node → Backend API → Database → Web Dashboard

 Technologies

Hardware:
- ESP32
- Sensors
Software:
- React
- Tailwind CSS
- FastAPI
- PostgreSQL
- Python Analytics
